# Cohort-Based Targeting

Target users with surveys based on **pre-defined groups** in PostHog.

## Why Cohort-Based Targeting?

Cohorts let you create reusable user segments that can be targeted across surveys, feature flags, and experiments:

- **Dynamic cohorts** - Automatically update as users meet criteria
- **Static cohorts** - Fixed lists of users (e.g., beta testers)
- **Behavioral cohorts** - Based on event sequences and patterns

## Understanding Cohorts

Cohorts in PostHog are groups of users who share common characteristics or behaviors.

### Dynamic vs Static Cohorts

| Type | Updates | Best For |
|------|---------|----------|
| Dynamic | Automatically | Behavioral segments, lifecycle stages |
| Static | Manually | Beta groups, specific user lists |

### Step 1: Create Your Cohort

First, define your cohort in PostHog:

```
Cohort: "Checkout Abandoners"
Criteria:
  - Performed event: add_to_cart
  - Did NOT perform event: checkout_completed
  - In the last: 7 days
```

### Step 2: Link Cohort to Survey

In your survey's display conditions, select "Cohort" and choose your target cohort.

## Common Cohort Patterns

### Lifecycle Cohorts

```
"New Users" - Signed up in last 7 days
"Active Users" - Performed any event in last 30 days  
"At-Risk Users" - No activity in last 14 days
"Churned Users" - No activity in last 60 days
```

### Behavioral Cohorts

```
"Power Users" - More than 50 sessions in last 30 days
"Feature Adopters" - Used feature X at least 3 times
"Upgrade Candidates" - Hit usage limits twice
```

### Product Flow Cohorts

```
"Onboarding Complete" - Completed all onboarding steps
"Checkout Abandoners" - Added to cart but didn't purchase
"Trial Expiring" - Trial ends in next 3 days
```

## Best Practices

:::tip Start with Existing Cohorts

Before creating new cohorts for surveys, check if relevant cohorts already exist in your PostHog instance.

:::

:::caution Cohort Size

Very small cohorts may not generate statistically significant survey results. Aim for cohorts with at least 100+ members.

:::
